## 10. 距离"生产级可用"还差什么

1. **多用户/公网部署能力**：换 WSGI 服务器（waitress）+ 鉴权 + TLS；目前是 Flask 开发服务器 + 无鉴权（本地定位）。
2. **持久化与并发**：会话/记忆是 JSON 文件（单进程友好），多实例需换 SQLite/Postgres。
3. **可观测性扩展**：指标目前覆盖抓取插件；建议加进程级 CPU/RSS、请求追踪 ID。
4. **重依赖模块的自动化**：视频/播客/音乐/安装器需独立测试通道。
5. **依赖安全扫描**：`pip-audit` 纳入 CI（需网络）。
6. **长跑与压测常态化**：24h 稳定性 + 并发压测接入定时任务。
