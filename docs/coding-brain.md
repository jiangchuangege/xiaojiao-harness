# 🧠 编码大脑 + 8G 显存管理（秒级双脑）

小焦现在有**两个本地大模型 + 一个视频 + 一个音乐**能力，靠 llama-swap 统一调度，8G 显存下跑得又快又稳。

|---|---|---|---|

## 8G 显存管理规则（唯一正解）
```
显存(RUN) 只允许 1 个:  聊天4B / 编码8B / 视频Wan  任一时刻最多一个
内存(WARM) 只允许 1 个: 上次用的大脑(切回秒级), 被新的顶掉就彻底卸载
切换 X:  顶掉旧WARM(卸载) -> 当前RUN去WARM(温存) -> X上显存
生成前:  自动卸载另一个llama(内存守卫) -> 当前大脑独占显存全速
```

- **谁在用谁全速**（独占显存，不抢）。
- **上次用的留内存**（切回秒级：内存→显存）。
- **防双模型驻留 OOM**（切走 = 真卸载，不是只改标记）。

## 禁用思考（关键提速）

- 关掉后：直接回复 + 正常调工具，**快很多**。上下文统一 20000。
