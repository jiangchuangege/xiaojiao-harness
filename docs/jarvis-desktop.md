# 🐳 桌面贾维斯 MVP：会动会说话的小焦宠物

> **一句话**：桌面宠物让 AI 从"工具"变成"伙伴"——普通用户愿意装、愿意打开、愿意天天互动，这是纯网页版永远给不了的陪伴感。

## 核心理念
- **表现形式**：透明置顶、会动会说话的桌面宠物（Live2D/Spine）。
- **大脑**：小焦作为后台 Agent（已有：意图理解/任务规划/工具调用/记忆）。
- **交互**：自然语言 / 点击宠物弹输入框。
- **MVP 边界**：仅三大场景——①环境配置 ②文件整理 ③咨询问答；安全策略 **"AI 只建议，用户动手执行"**。

---

## 1. 技术选型
| 层 | 选型 | 理由 |
|---|---|---|
| 宠物渲染 | **Live2D**（WebGL） | 社区免费模型多、动效好；Spine 备选（性能更优但资源少） |
| 桌面壳 | **Electron**（MVP） | 内置 Chromium 渲染 Live2D 零障碍；Tauri 备选（轻量，后续可换） |
| 通信 | **本地 WebSocket**（127.0.0.1） | 宠物前端 ↔ 小焦后端 Flask(5000)，同机零延迟、无跨域问题 |
| 语音 | Web Speech API（可选 MVP+） | 先说后听，MVP 以文字为主 |
| 后端大脑 | 小焦 `agent_run`（已有） | 意图/工具/记忆/成本全复用，不重造 |

架构：
```
Live2D 宠物(Electron, 透明置顶窗口)
   │ WebSocket(127.0.0.1:5001)
小焦后端 Flask(5000) — agent_run(意图→工具→回复)
   │
本地大脑(llama-swap 9292) + 工具全家桶(14个)
```

## 2. 插件开发清单（MVP 三个）
| 插件 | 工具 | 安全策略 |
|---|---|---|
| **环境检测** | `check_env(pkg)`：检测 python/git/node 是否装、版本 | 只读检测；给安装建议，**不执行** |
| **文件整理** | `suggest_organize(dir)`：列出建议（按类型/日期归档到哪） | 只给"建议清单"，用户点确认才移动 |
| **搜索咨询** | 复用 `web_search`（天气/新闻） | 只读，展示来源 |

> 全部复用现有工具骨架：run_command(检测用,只读) / list_files / web_search，MVP 零新后端逻辑。

## 3. 用户引导流程（首次启动）
1. **宠物自我介绍**："你好，我是小焦～我可以陪你聊天、帮你整理文件、查天气。"
2. **自动环境检测**（后台 check_env）→ 宠物气泡："我发现你还没装 Python，**建议**装一下，要我教你怎么装吗？"
3. **教用户执行**：用户点"教我"→ 宠物一步步提示（下载链接→运行安装→验证），每步等用户反馈，**全程用户自己动手**（AI 只建议）。
4. **三大场景引导**：弹三张场景卡片（装环境/整理文件/查资讯）→ 点一个试一下。
5. **完成**："都好了！以后有需要随时叫我～"

## 4. 发布计划（双击即用安装包）
```
[安装包 xiaojiao-setup.exe（Inno Setup 制作）]
 ├─ 小焦后端（PyInstaller 打包 xiaojiao_app.py → xiaojiao-server.exe）
 ├─ 桌面宠物（Electron 打包 Live2D 前端 → xiaojiao-pet.exe）
 ├─ 依赖预置（llama-swap + 模型校验/首次自动下载）
 └─ 启动器（launcher.exe：先起后端 → 再起宠物 → 托盘常驻）
```
- **Inno Setup** 把三者捆绑 + 生成桌面快捷方式 + 开机自启（可选）。
- 双击 `xiaojiao-setup.exe` → 安装 → 双击桌面图标 → 宠物出现。
- 首次运行自动检测硬件 → 推荐下载模型（见 upgrade-plan 零门槛安装）。

## 5. 为什么比"纯网页版"更吸引普通用户
> **网页版是"打开才能用的工具"；桌面宠物是"一直在身边的朋友"**——会动、会说话、置顶可见，降低使用门槛、制造情感连接，让用户**主动打开、天天互动**，这是普通用户愿意留下并传播的关键。
