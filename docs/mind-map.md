# 小焦的心 · 脑 · 情绪 · 表达 —— 一张图

> 这份文档回答一个问题：**"心"到底接通了没有？它怎么一路走到 B站 去说话的？**
>
> 图里每个方框都对应仓库里**真实存在的模块**（不是示意图），括号里是文件名。
> 想核对哪一环，直接打开那个文件。

## 二、五层各自的职责（一句话说清）

| 层 | 它回答的问题 | 主要模块 | 断没断 |
|---|---|---|---|
| **① 脑** | "这件事该怎么想？" | `memory_deep.py`、`retriever.py`、`memory_gate.py` | ✅ 通 |
| **② 心** | "这对我意味着什么？我在乎吗？" | `inner.py`、`self_model.py`、`spirit_memory.py`、`heartbeat.py` | ✅ 通 |
| **③ 元认知** | "我这样想/这样说，对不对？" | `self_audit.py`、`consensus.py`、`proof_panel.py`、`self_evolve.py`、`memory_upkeep.py` | ✅ 通 |
| **④ 情绪** | "我现在什么心情、还有没有劲说话？" | `interoceptive.py`、`energy.py`、`feeling_memory.py`、`dual_thread.py` | ✅ 通 |
| **⑤ 表达** | "对谁说、说什么、怎么说" | `friends.py`、`ai_group.py`、`moments.py`、`bili_duty_ui.py` | ✅ 通 |

**所以"心"是接通的**：它不是一个装饰性的设定，而是
`inner` 的可升降量 + `self_model` 的立场 + `spirit_memory` 的认知，
三者一起影响 ④ 的情绪，再影响 ⑤ 说出去的话。

**元认知是"刹车"**：`self_audit` 事后检查、`consensus` 多火种对账、
`proof_panel` 要求给依据 —— 它们决定"这句话该不该发出去"。

## 三、一次"B站 有人 @ 它"的完整走位

```
B站 有人 @ 了它
   │
   ├─① 脑：bili_received_at_and_likes 拿到通知
   │      → bili_subtitle 取这条视频到底讲了什么（_video_digest）
   │      → memory_gate 判断要不要动用长期记忆
   │
   ├─② 心：这件事对我意味着什么？
   │      → self_model 的立场（"我是个嘴硬但会接话的人"）
   │      → spirit_memory 里学到的相关认知
   │
   ├─③ 元认知：这样说行不行？
   │      → proof_panel 有没有依据
   │      → self_audit 会不会重复上次的错
   │      → consensus（多火种时）对不对得上
   │
   ├─④ 情绪：energy.level 还够不够、feeling_memory 里对这人什么印象
   │      → 决定"要不要回、回多长、什么语气"
   │
   └─⑤ 表达：llm_chat 按人设写一句话
          → 过三道清洗：去旁白 / 去"回复某某："前缀 / 剥思考标签
          → bili_reply 发出去（先试通知 id，失败退回评论树根）
```

**这条链是通的**，而且每一步都有落盘记录（`logs/` 下的 jsonl 与 reports）。

## 四、现在的短板（诚实标注）

| 环节 | 现状 | 缺什么 |
|---|---|---|
| 心的**连续性** | `inner.py` 有可升降的量，但**没有跨会话的完整自传** | 一条"我是谁、经历过什么"的长期叙事 |
| 情绪的**归因** | `feeling_memory` 记了情绪，但**不解释为什么** | 情绪 → 事件的因果链 |
| 表达的**分寸** | 靠提示词约束（禁旁白/禁前缀） | 缺一个"这话像不像人"的自动评分 |
| 记忆**证据链** | `spirit_memory` 已加 `basis`/`verified` | 还没把证据展示到界面上 |

---

## 五、一句话总结

> **心在中间，脑在下面，情绪在边上，嘴在上面。**
> 心不是标语，它是 `inner` 的那几个数、`self_model` 的那个立场、
> 和 `spirit_memory` 里那一句句"我以前想明白的事"。
> 它们一起决定：**它此刻想不想说话、以及说出来的像不像它自己。**
