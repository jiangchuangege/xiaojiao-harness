## 🎯 为什么值得做（市场/情感）

市面上的 AI 助手都是**"打开网页才用"**的工具。小焦想解决的，是让人**把 AI 当成"一直住在身边的伙伴"**——会动、会说话、置顶可见、能主动找你。这种**陪伴感**，是纯网页版永远给不了的。

- 普通用户：一个会陪你的本地猫娘，**装了就天天打开**
- 开发者：**零门槛接入**多大脑 + 插件生态，随便加能力
- 极客：**真·本地离线**、真·能生成视频/播客，不依赖云端

---

## 🧪 技术硬实力（不打嘴炮）

- **多大脑调度中心** `brain_manager.py`：RUN(WARM/OFF) 三种状态，显存↔内存秒级切换
- **真·文生视频** `video_service`：ComfyUI+Wan2.1 本地生成 **或** Agnes 云端 API（免费，1RPM 节流）
- **真·播客大脑** `podcast_service`：LLM 写稿 → Chatterbox 配音 → pydub 拼接 → SD1.5 封面
- **猫娘桌面伙伴** `neko`：N.E.K.O. 猫娘，透明置顶 Live2D，`learn_from_neko.py` 学你与猫娘的对话
- **插件万能桥**：自动把 OpenAI/Claude/DSH 工具 manifest 转成小焦工具
- **成本看板**：实时统计调用/Token/花费/节省

## 🖥️ 怎么跑（3 行）

```powershell
cd xiaojiao
pip install -r requirements.txt
python start_xiaojiao.py   # 拉起多大脑 + 网页；再问一句是否同时启动桌面猫娘（可选）
```

打开 `http://127.0.0.1:5000`；猫娘选 `y` 的话，桌面上一只猫娘就出现了。
