# 🐳 小焦 v1.0 · 首个正式版

> 本地部署的 AI 助手：会**联网检索**、会**抓网页**、会**查 NVD 漏洞**、会**写文件跑命令**，
> 还带一颗自研的会学习的小脑。**全离线可跑，密钥不外传。**

**本版定位**：把"能跑起来"变成"能稳定用" —— 补齐了抓取、漏洞情报、检索质量、
界面体验、质量闸门，并修掉一批真实缺陷。

---

## ✨ 这一版能做什么

| 能力 | 说明 |
| --- | --- |
| 🔍 **联网检索** | 免密钥 Bing / Sogou / DuckDuckGo；检索词自动清洗，**还会校验回答有没有真读资料** |
| 🕷️ **网页抓取** | 内置 Scrapling **18 个工具**：网页 / 动态页 / 接口 / 批量 / 登录态 / 截图 / 下载任意文件 |
| 🛡️ **漏洞情报** | 说「抓最近 7 天的高危漏洞」→ 走 NVD 官方接口（**强制时间窗**），直接出 Markdown 表格 |
| 🧠 **小脑（自研）** | 蒸馏小模型，越用越懂你的用法；路径全自动探测，不写死 |
| 🧰 **工具执行** | 写文件 / 建网页 / 跑命令 / 开应用，危险动作可控（Full access ↔ Read-only 一键切） |
| 🎭 **Agent 预设** | 人格 + 大脑 + 工具开关打包切换（闲聊陪伴 / 编程助手 / 自定义） |
| 🎬 **多模态** | 文生视频（云端 API 或本地 ComfyUI+Wan2.1）· 播客配音 · 音乐生成 · 语音通话 |
| 📊 **可观测** | `/metrics`（Prometheus）· JSON 指标 · 会话自动回收 · 全链路日志脱敏 |

## 🎨 界面

- **居中输入卡片**：与对话内容共用同一轴线，Enter 发送 / Shift+Enter 换行 / 自动长高
- **代码块语法高亮**：Python、JS、JSON、Bash、SQL、CSS、HTML

- **会话管理**：新建 / 切换 / **删除**（侧栏每行 ✕）

## 🐞 本版修复（挑主要的）

| 问题 | 结果 |
| --- | --- |
| 漏洞查询不带时间窗 → 拿到 1999 年数据、受影响软件全 `n/a` | 新增 `collect_vulnerabilities`：时间窗 + 结构化表格，软件名 5/5 行都有 |
| 搜索把「用」「你」这种功能字当关键词 → 搜出百科词条 | 检索词清洗闸门：清洗后无内容就反问用户，绝不拿单字去搜 |
| 搜「最近 AI 新闻」返回歌曲《最近》/词典词条 | 多变体 + 主题词覆盖率判断 + 词典词条降权，实测结果全部变成真新闻 |
| 深色模式代码块像有"白色底纹" | 根因是 `code` 元素背景叠加，已清干净 |
| 回答里冒出 `<think></think>` | 后端 + 前端双重剥离 |
| **Agent 预设设置了不生效** | 面板从未渲染 + 选择器元素不存在，现已接通并做行为级验证 |
| **侧栏会话删不掉** | 新增删除接口 + 每行 ✕ 按钮 |
| 日志脱敏把参数转成字符串 → `%d` 型日志全报错 | 改为先渲染再脱敏（熔断告警不再被吃掉） |
| CI 一直是红的（控制台编码） | 入口脚本统一 UTF-8 + workflow 加 `PYTHONUTF8=1`；现全绿 |
| 5 处潜在崩溃（多脑唤醒失效 / 切人设 500 / 语音预热白做 …） | 全部修复并纳入静态检查门槛 |

## ⚠️ 已知限制

- 视频 / 播客 / 音乐链路依赖 GPU 与外部模型，未纳入 CI
- 稳定性压测用 `tests/stress/stability_30m.py`（30 分钟无头压测，纯插件、不消耗任何大模型 Token）
- NVD 无 API Key 时限流较严（5 次/30 秒），偶发限流会自动退避重试一次
- ruff 目前只把**真 bug 级规则**纳入门槛，风格类规则未清零
