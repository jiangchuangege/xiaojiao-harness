# 小焦 v1.1.0 · 提示词分层重构 + 校验熔断

> 目标一句话：**人设归人设、规则归代码、插件自动进清单；多步工作流不再"改一条试一次"。**

## 本轮修复项

### 1. 系统提示词分层重构（架构缺陷）

- `compose_system_prompt(role, plugins)` 固定四段拼接：
  `role（纯人设） + _SEARCH_RULES + _TOOL_RULES + _plugin_list()（从 PLUGINS 动态生成）`
- `_plugin_list()` 动态生成工具清单（工具名 + 一句话描述，去重、超量折叠）；
  `load_plugins()` 末尾 `refresh_system_prompt()` 重建提示词 →
  **往 `plugins/` 丢一个新 `.py`、重启即生效，不需要改人设**。
- `strip_search_rules()` 升级为剥掉**所有**规则类片段，只留纯人设（幂等）。
- Archify 工作流从 `role` 搬进 `plugins/archify.skill.md`；用户 role 743 字 → 纯人设一句。

### 2. `archify_validate` 反复重试（性能）

- 校验失败**一次列全所有报错**：字段路径 + 报错 + **建议修法**，并注明「一次改完，再校验一次」。
- 同一工具**连续失败 3 次熔断**：停止重试、轨迹标注「已熔断」、把最后一次报错原文给用户。
- 校验失败落盘 `logs/archify_validate.log`。
- 实测：同一画图指令 **287 秒 → 39 秒**，validate 真实调用 **7 次 → 3 次**。

### 3. 别搜闸门 & 工具直通（行为一致性）

- 用户说「别搜/停止搜索/不要联网/直接调用某工具」→ 一次搜索都不发。
- 点名已加载工具（Archify / net_ip…）→ 不联网搜，直接走工具；
  点名零参数/全可选参数工具 → **直接调用**。
- 「抓一下 `<url>`」改为**规则直通**（模型之前先判）：同一句话结果稳定一致。

### 4. 其余修复

- 公网 IP 问句直答 `net_ip`（模型此前会编 IP、或给 `[查询结果]` 占位模板）。
- 云端大脑失效自动兜本地大脑（并如实标注），连续失败熔断 60 秒；切换模型时用 chat 实测。
- 幻影工具（外部清单里没写 url、执行不了的）不再进工具表；`plugins/ip.json` 这类正常插件已恢复。
- 资产测绘插件 `plugins/asset_intel.py`：IP → 命中哪些 CVE（免费无 Key）；CVE → 受影响 IP（配 Key）。

## 升级说明

1. **无需改配置**：旧 `xiaojiao_control.json` 直接用；里面若残留规则文本（检索铁律 /
   Archify 工作流 / 工具清单），启动时会自动剥离，只保留人设。
2. **插件自动进清单**：新增插件只需把 `.py` 放进 `plugins/` 并重启；工具清单由代码生成。
3. **画图工作流**：Archify 的使用步骤现在作为技能文档随插件加载
   （`plugins/archify.skill.md`），不再要求写进人设。
4. **校验失败会熔断**：同一工具连续失败 3 次会停止重试并把最后报错交给你 ——
   这是有意设计，避免"改一条试一次"空转。
5. 备份位置：本轮改动前的 `xiaojiao_control.json` / `xiaojiao_app.py` / `archify.py`
   已备份在 `logs/backup_before_refactor/`、`logs/backup_before_validate_fix/`（均不入库）。
