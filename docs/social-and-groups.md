# 社交层与群聊：这一轮到底改了什么

> 本文记录 2026-11-13 ~ 11-14 这一轮对**社交（好友 / 群聊 / 朋友圈）**、**插件模块**、
> **学习注入**、**网页取证**的改造。每条都写清楚：**改之前是什么样、为什么改、改完怎么验的**。
>
> 阅读前先记住一句总纲：小焦不依赖任何具体模型。它是完整的载体（器官齐全），模型是火种
> （可替换）。所以下面所有修正都落在**载体侧**——不指望换一颗更聪明的火种来解决。

---

## 1. 消息里混进"思考块"

**现象**：好友回复、群聊发言里出现整段内心独白，甚至是空的 `</think>`。

**根因**：模型会换着写法输出推理段，`<思考>`、`</think>`、`【思考】…【回答】` 三种都有；
而剥标签的逻辑**一条路径只认一种**，且好友/群聊是**另外两条落盘路径**，根本没走到那条逻辑。

**改法**：三处统一认三种写法。

| 位置 | 函数 |
| --- | --- |
| 聊天主链路 | `xiaojiao_app._strip_think` |
| 好友聊天 | `core/friends._strip_think_local` |
| 群聊 | `core/ai_group._clean_group_text` |

规则：有 `【回答】` 就只留它后面的；没有就整段删；**洗完为空就不发**（不发空壳、不发内心话）。

**验证**：`_strip_think('【思考】…【回答】\n我是一个 AI…')` → `'我是一个 AI…'`；
`'【思考】只有思考没有回答'` → `''`。

## 2. 同一条回复重复出现

**现象**：好友聊天里每条回复显示两遍（同一时间、同一内容）。

**根因**：前端 `oneSig()` 的消息签名**故意不含 id**，只用"发送方 + 长度 + 前 16 字"。
连发同一句「在干嘛呢」时这些消息签名完全一样，增量追加分不清哪条是新的 → 同一条被追加两次。

**改法**：签名优先用 id（稳定唯一），并在 `patchMessages` 里按 id 去重。

**验证**：真页面里 `dedupeMsgs([{id:'a'},{id:'b'},{id:'a'}])` → 2 条；
`oneSig({id:'zz'})` → `'id|zz'`。

---

## 3. 群聊里"我说话没人理"

**现象**：用户在群里说话，AI 继续说自己的，像没听见。

**根因（两层）**：
1. `_transcript(msgs, who_filter)` 按 `who_filter`（**这一轮谁该发言**的成员名单）过滤，
   而过滤是按**每条消息的发言人**做的 —— `你` 不在名单里就被整条丢掉。
   于是 AI 只能看到彼此，看不到用户。**"谁说的"不该被"谁该发言"决定。**
2. 即使把用户的话塞进上下文，4B 也会忽略（群聊 prompt 里有十几条互相竞争的约束）。

**改法**：
- `_transcript` 里用户的话**永远保留**；
- 新增 `_reply_to_user()`：用户说话时走**单任务通道**（一句话、一个要求、上下文只留 3 条），
  不再交给群聊那条复杂流水。

**验证**：`_transcript([...], ['小焦','老曲'])` 的输出里仍有 `你：…`。

**已知未解**：`_ask` 在这条路径上偶发返回空（`('', '')`），群里会突然没声。未定位到根因。

## 4. 群聊在"演戏"：编造仓库、star 数、链接

**现象**：群里说"我找到了 XXX 插件，★320、评分 4.8"，链接点开 **404**。

**根因**：让 4B 自己调 `github_find_plugin`，它**调了工具、不看结果**，照样照"应该长什么样"编一段；
连"已安装成功"也编。提示词压不住。

**改法（三道闸 + 一条真路）**：

| 闸 | 规则 |
| --- | --- |
| 伪造卡片 | 出现 `【插件名称】/【插件评分】/【插件 star】…` → **删掉卡片部分**，保留人话（整条丢会让群哑掉） |
| 无凭证 | "已安装/已下载/链接/数字/找到了"这类断言，本轮没真调过工具 → 拦 |
| 链接 404 | 消息里的 GitHub 链接**发出去之前真访问一次**，404 当场改写为「这个链接 404，仓库不存在，是编的」 |

**真路**：`plugins/github_plugins.py` 提供 `plugin_spec` / `github_find_plugin` /
`github_install_plugin`（下载 → 静态检查 → 沙箱试跑 → 通过才落盘，验不过自动撤掉）。

**验证**：
```
github.com/xiaojiao/plugin-framework-xiaojiao → 404 → 被标出
github.com/python/cpython                     → 200 → 原样保留
```

## 5. 剧本群（后宫戏）

**需求**：用户要能**粘贴一整段剧本**（主题 / 语言风格 / 互动规则 / 角色人设），不用一条条填。

**接口**：`POST /api/aigroups/<gid>/script`，正文 `{text: "…"}`。
`core/ai_group.set_script()` 解析成 `topic` / `style` / `rules` / 每个角色的 `persona`，
并且：
- **剧本里没有的成员会被清掉**（建群时自动塞的小焦/阿码/老曲不该混进后宫）；
- 自动打上 `mode="roleplay"`。

**剧本群的特殊待遇（关键）**：
- **防编造四道闸全部跳过** —— 演剧本时"编"正是内容（用户原话："编造就是编造，我要让他们演到极致"）；
- **不给工具** —— 否则会把 `text_stats】`、`forge_plugin` 这种念进台词里；
- **现代词后处理** —— `_de_modern()` 把手机→帕子、屏幕→桌案、语音→轻声道…

> 为什么用后处理而不是提示词：实测写三条铁律 → 4B 直接哑掉（整轮 0 条）；
> 缩成一句 → 它照样写"（把手机在眼前推了推）"。压不住就换词。

## 6. 插件模块与命名

**规则**（按用户口径）：

| 插件类型 | 行为 |
| --- | --- |
| 老插件 | 不出独立页签（放回原样） |
| 老插件声明了 `settings` | 出页签 |
| 新造的（`gen_*`） | **自动出独立模块**：按参数 schema 生成输入框 + 「▶ 执行」 |
| 新造的但"简单"（时间/天气/换算/编解码，且参数 ≤1） | 不出（让 AI 直接答） |

**名字与图标**：不再显示 `gen_cap_20261027_173718`，也不再一律用匕首。
`pluginMeta()` 从工具说明里推断可读名字（去掉括号举例、去掉开头"把"、截 10 字），
并按功能关键词配 15 类图标（📺 🖼️ 🎙️ 🌐 📁 🧩 📝 🗄️ ⏰ 🌤️ 📬 🔐 📍 🔢）。

**顺带修掉的 bug**：页签 `data-sec` 写的是 `<插件名>`，而区块 id 是 `sec-plug-<名>`，
两边永不匹配 → **所有"有配置项的插件"设置页一直是空白**。已改成 `data-sec="plug-<名>"`。

## 7. GitHub 检索与网页取证

- `plugin_spec`：插件硬规定（必须 6 条 / 不支持 5 类）
- `github_find_plugin`：GitHub 仓库搜索（星数排序，返回真实链接）
- `github_install_plugin`：raw 直链下载 → 静态检查 → **沙箱三组真参数试跑** → 通过才落盘
- `web_shot`：**真开浏览器截图**，图存在 `logs/weblog/<hash>.png`，路由 `/weblog/<file>`

> 截图的意义：模型说"我打开了 X 页面"无法核实；截图能证明**这个页面长什么样**。
> GitHub 禁止 iframe 嵌入，所以只能截图，不能嵌页面。

## 8. 学习注入改成"精度优先"

**实测**（`tools/verify_stronger.py`、`tools/verify_learn_fair.py`）：
- 工具：**变好 3 / 持平 1 / 变差 0** —— 从"不敢答"到"给出准确数字"，是真变强；
- 学习：**变好 1 / 持平 3 / 变差 1** —— 注入记忆对常识题是**负收益**。

**根因**：原来 top-3 **无条件**注入；这份嵌入对任何两句都给 0.62~0.82
（"下班回家先做什么" 召回 "用户住在菏泽。"，sim=0.661），拿相似度当门槛等于没门槛。

**改法**：`_spirit_recall()` 两道闸 —— 问题与认知**共享 ≥2 个 ≥2 字实词**，或相似度 **≥0.78**；
否则一条都不注。**代价**：学到的东西起作用的机会变少（precision 优先）。

## 9. 数据安全（一次真实事故换来的）

**事故**：`logs/aigroups/groups.json` 被写成 `{"groups": []}`，**整个群和聊天记录全丢**。
根因是三个线程各自 `_load → 改 → _save`，读到旧（空）副本的线程把空数据覆盖上去。
而这个文件**从来没有备份**。

**改法**（`core/ai_group._save`）：
1. 保存前把旧文件备份成 `.bak.1 ~ .bak.5`；
2. **拒绝"用空覆盖有"**：现有群数 > 0 而新数据群数 == 0 → 直接拒绝写入。

**验证**：`_save({"groups": []})` → `False`，日志 `拒绝用空数据覆盖 1 个群`。

> 未做：把三处读写统一到同一把锁下（真正病根）。目前只靠"拒绝空覆盖"兜底。

## 10. 其他修掉的小毛病

- **好友名字带 `/` 点不开**：`皇上（四郎/胖橘）` → Flask `<name>` 不匹配斜杠 → 请求 404。
  4 个好友路由改为 `<path:name>`。
- **聊天区总被拽回底部**：`setInterval(fitChat, 2000)` 每 2 秒无条件滚到底，
  向上翻历史就被拉回去。改为 `fitChat(force)`：只有"本来就在底部"才跟随。
- **群里工具回执糊成一坨**：载体消息里的工具输出改为 ```` ``` ```` 围栏渲染。
- **群聊跑题不落盘**：与群主题**双字滑窗**无重合 → 只进日志、不进消息（技术群才管，剧本群放行）。
