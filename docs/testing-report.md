## 4. 稳定性

### 已做的等效抽样
- **连续 20 次调用**：Python 堆净增 **0.10MB**（无泄漏迹象），20/20 成功。
- **熔断 + 自愈**：失败 3 次触发，**32 秒后自动恢复**（不是永久禁用）。
- **会话回收**：TTL/空闲/LRU 三规则生效，**浏览器会话不会无限堆积**。
- **5 并发**：无崩溃、无数据串扰。

### 30 分钟无头压测（脚本已备，自己在终端跑）
```powershell
python tests/stress/stability_30m.py --minutes 30 --interval 10
```
- 每小时抓 10 个 URL，记录：成功率、P95 延迟、Python 堆增长、异常/崩溃
- 结束输出 `stability_report.json` + Markdown 摘要，并对"P95 是否衰减/堆是否持续增长"给出结论
- **本轮未执行真 24 小时**（受会话时长限制）—— 属已知缺口

> **CI 曾经一直是红的（本轮修掉，现已全绿）**：runner 控制台编码不是 UTF-8，`check_mermaid.py` 打印中文时
> 抛 `UnicodeEncodeError`，导致每次运行都卡在第一步质量闸门、压力测试**从未在 CI 里执行**。
> 现在所有入口脚本启动时把 stdout/stderr 切成 UTF-8，workflow 也加了 `PYTHONUTF8=1`，
> 本地用 `PYTHONIOENCODING=cp1252` 复现并验证修复（退出码 0）。
>
> **修好后第一次全绿运行**（run 34691282396）：Mermaid / 静态审计 / 文档一致性 / ruff / 压力测试
> 五道闸门全部通过，CI 里实测 **217/217 通过 · 通过率 100%**。
> 唯一 1 条跳过是**应用逻辑套件**：CI 未安装 flask/torch，主程序加载不了 → 按设计**跳过**；
> 本地环境该套件全部通过，所以本地是全量套件。

## 6. 结论与后续

**结论**：抓取插件、应用层检索/漏洞规则与安全闸门已达"可交付"水平（237/238 + 实机 36/36、无高危未修项）；
**全项目**（视频/播客/音乐/安装器/小脑训练）的自动化覆盖仍不完整，属"可运行但未完全自动化"。

**建议优先级**：
1. 给小脑推理与记忆检索补最小单测（改动最频繁、回归代价最高）。
2. 安装器加 `--dry-run` 模式后纳入 CI。
3. 跑一次 30 分钟无头压测（`stability_30m.py`）把结果写回本报告。
4. 给 NVD 漏洞聚合配一个免费 API Key（`XIAOJIAO_NVD_API_KEY`），彻底摆脱 5 次/30 秒的限流。
