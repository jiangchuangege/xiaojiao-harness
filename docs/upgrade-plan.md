# 🚀 小焦升级方案：对标 DeepSeek Harness，走差异化路线

> **定位一句话**：Harness 是给开发者的多智能体编排平台；**小焦是给所有人的"一句话就能拥有、按需省钱、万物可插"的本地 AI 管家**。

## 差异化打法
| | DeepSeek Harness | 小焦 |
|---|---|---|
| 用户 | 开发者/技术团队 | **普通人（零门槛）** |
| 安装 | 需 Node/依赖/配置 | **一句话自动装好** |
| 成本 | 全云端按量计费 | **本地为主省钱，复杂才上云** |
| 插件 | DSH 生态 | **通吃 DSH/OpenAI/Claude** + 自然语言生成 |

---

# 阶段一：技术实现（第 1-2 月）

## 1.1 零门槛安装：从"配置"到"对话"
- **硬件自动检测**：启动即探测 GPU 型号/显存/内存/硬盘/网络。
- **自动推荐模型**：按显存分档给推荐（如 8G→Qwen3-8B；4G→4B；无 GPU→CPU 版或云端模式）。
- **自动下载模型**：多镜像（hf-mirror / 魔搭 ModelScope）+ 断点续传 + 自动重试；下载后**校验和验证 + 测试生成一次**确认可用。
- **一键写配置**：检测→推荐→下载→写 llama-swap/control→完成，全程零手改文件。
- **结果呈现**：安装完成后宠物/向导说"我准备好了，试着问我问题吧"。

**风险与应对**
| 风险 | 应对 |
|---|---|
| 下载慢/中断 | 多镜像 + 断点续传 + 自动重试（已具备骨架） |
| 硬件太老/不兼容 | 自动降级：CPU 模式 / 纯云端模式 / 无模型对话 |
| 磁盘不足 | 下载前检查空间，提示清理或选更小量化 |

## 1.2 智能调度：本地省钱 + 云端兜底 + 成本透明
- **路由判断**：
  - 简单闲聊/单轮 → **本地 4B**（免费、快）
  - 写代码/工具类 → **本地 8B 编码大脑**
  - 复杂推理/长文/多步 → **云端 API**（deepseek-chat 等）
- **判断器**：本地小模型快速打分（复杂度/意图）或轻量规则（长度、关键词、工具意图、置信度阈值）。
- **无缝切换**：云端调用时用户无感知（加载态即可）；云端超时/断网 → **自动降级本地**并提示。
- **成本看板**：每次云端调用记录 token → 按单价换算金额 → 首页显示"**今日为你节省 ¥X**"（= 若全云端的费用 - 实际花费）。

**风险与应对**
| 风险 | 应对 |
|---|---|
| 误路由（简单问题上云烧钱） | 置信度阈值 + 用户可"强制本地/强制云端" |
| 云端限流/延迟/断网 | 超时自动降级本地 + 重试 + 本地缓存 |
| 用户不信任"自动上云" | 默认本地优先；上云前可提示"这条较复杂，用云端(约¥0.01)？" |

## 1.3 插件万能桥：DSH/OpenAI/Claude 通吃 + 自然语言造插件
- **统一工具协议**：把 DSH 插件、OpenAI function-calling、Claude tool-use 统一成小焦的内部工具描述（已有 `_build_tools` 骨架，加适配器层）。
- **适配器**：`adapters/dsh`（读 DSH 插件目录）、`adapters/openai`（读 tools.json）、`adapters/claude`（读 tool manifests）→ 自动注册进工具列表。
- **即插即用**：用户把插件文件丢进 `plugins/` → 自动扫描注册（现有机制）→ 设置页可见可开关。
- **自然语言生成插件**：用户说"帮我写个查天气的插件" → 编码大脑生成插件代码 → 自动写进 `plugins/` → 注册 → 立刻可用（现有 addlocal/插件模式延伸）。

**风险与应对**
| 风险 | 应对 |
|---|---|
| 各生态参数格式不同 | 适配器层统一 schema（含 parameters.type 规范化，已修） |
| 恶意/质量差插件 | 沙箱运行 + 权限确认（run_command 等需确认）+ 插件来源评分 |
| 生成的插件有 bug | 生成后自动 `python -c` 语法校验 + 测试调用一次再启用 |

# 阶段二：产品体验（第 2-3 月）

- **对话即配置**：用户说"我要离线隐私/我显存小/我要省钱" → 自动切换对应大脑与调度策略。
- **成本看板页**：每日节省金额、云端调用次数、柱状图、Top 提问。
- **插件市场页**：内置商店（卡片式一键安装，复用 Agent 预设卡片样式）。
- **桌面贾维斯**：见 `docs/jarvis-desktop.md`（透明宠物，会动会说话）。
- **新手引导**：首次启动三步引导（选场景 → 自动配置 → 试一句话）。

**风险与应对**
| 风险 | 应对 |
|---|---|
| 功能太多，普通用户懵 | 渐进式 UI：新手模式（三大场景卡片）/ 高级模式（全功能） |
| 用户不知能干什么 | 场景化预设（"写作业""整理文件""查资料"一键场景） |
| 成本数字不准确 | token 按官方价换算，标注"估算" |

# 阶段三：社区运营（第 3-6 月）

- **开放插件 SDK**：文档 + 模板仓库 + 示例（照抄一个 20 行插件即可）。
- **官方先行**：先发布 20 个高质量插件（天气/新闻/文件/代码/翻译/音乐…）立标杆。
- **插件大赛**：月度"最佳插件"评选，奖励贡献者（荣誉 + 仓库 star + 教程曝光）。
- **品牌口号**："普通人也能拥有的本地 AI 管家"；教程向 B 站/知乎/公众号分发。
- **低成本传播**：一键安装器 + 桌面宠物天然适合录屏演示。

**风险与应对**
| 风险 | 应对 |
|---|---|
| 没人写插件 | 官方先出 20 个 + 模板 + 激励 + "自然语言造插件"降低门槛 |
| 插件质量参差 | 评分/审核/沙箱 + 官方推荐标记 |
| 社区冷启动 | 先靠"零门槛+省钱+宠物"吸引普通用户，再导流开发者 |
